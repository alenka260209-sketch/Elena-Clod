# Elena-Clod

Рабочее пространство Елены и Claude: инструкции, заметки, шаблоны и
автоматизации.

## Что здесь есть

- **CLAUDE.md** — правила совместной работы (Claude читает его каждую сессию).
- **docs/** — справочные материалы и инструкции.
- **notes/** — заметки и итоги сессий.
- **tasks/TODO.md** — список текущих задач.
- **templates/** — шаблоны документов.
- **Битрикс24 → Google Календарь** — автоматическая синхронизация задач,
  см. `.claude/skills/bitrix-google-calendar/`.

## Как пользоваться на своём компьютере

Чтобы эти файлы появились в папке `Claude` на рабочем столе, склонируйте
репозиторий туда (например, через GitHub Desktop: *File → Clone repository*,
путь — `Рабочий стол/Claude`). Дальше изменения подтягиваются кнопкой
*Fetch/Pull*.
