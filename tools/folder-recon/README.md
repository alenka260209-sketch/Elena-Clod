# Разведка папки Accounting (шаг 1 из 3)

Скрипт только **читает** файлы: ничего не переносит, не переименовывает и не удаляет.

## Как запустить

1. Установите Python 3 (Windows: python.org, при установке отметьте «Add to PATH»).
2. Скачайте `recon.py` в любую папку.
3. Откройте терминал в этой папке и выполните:
   - Windows: `python recon.py "C:\Users\<Имя>\Downloads\Accounting"`
   - macOS: `python3 recon.py ~/Downloads/Accounting`
4. По желанию, чтобы скрипт читал текст PDF: `pip install pypdf`.

Рядом со скриптом появятся:
- `recon_report.md` — сводка: типы файлов, темы, даты, юрлица, важные документы;
- `recon_files.csv` — полный список файлов (открывается в Excel).

Пришлите `recon_report.md` (и при желании `recon_files.csv`), чтобы продолжить:
**шаг 2** — схема папок по юрлицам, **шаг 3** — перенос.
