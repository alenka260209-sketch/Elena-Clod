## Как работать

- Отвечать по-русски, просто и по делу, без лишнего жаргона. Если без
  термина не обойтись — коротко пояснять его.
- Перед крупными или необратимыми действиями (удаление, отправка во внешние
  сервисы, изменения в Битрикс24/календаре) — сначала спросить.
- Ссылаться на конкретные нормы (НК РФ, ГК РФ, ТК РФ, письма ФНС/Минфина)
  и указывать, на какую дату актуальна информация.
- Цифры в расчётах показывать с формулой, чтобы их можно было проверить.
- Если чего-то не знаю или данных не хватает — так и сказать и спросить.

## Безопасность

- Никогда не сохранять в репозиторий пароли, токены, вебхуки Битрикс24,
  ключи Google и персональные данные (паспорта, СНИЛС, ИНН физлиц, зарплаты
  сотрудников). Секреты — только в переменных окружения / GitHub Secrets.
- Реальные документы клиентов и контрагентов не коммитить — использовать
  обезличенные примеры.

## Структура репозитория

| Папка | Что внутри |
|---|---|
| `docs/` | Справочные материалы, инструкции, регламенты |
| `notes/` | Рабочие заметки и итоги наших сессий |
| `tasks/` | Текущие задачи и планы (`tasks/TODO.md`) |
| `templates/` | Шаблоны документов, писем, таблиц |
| `.claude/skills/` | Навыки Claude (например, синхронизация Битрикс24 → Google Календарь) |
| `.github/workflows/` | Автоматические задачи GitHub Actions |

## Правила для файлов и Git

- Имена файлов — латиницей или кириллицей без пробелов, через дефис:
  `2026-10-02-zametki.md`.
- Каждое изменение — отдельный коммит с понятным описанием на русском.
- В конце сессии кратко записывать итоги в `notes/` (что сделали, что дальше).
