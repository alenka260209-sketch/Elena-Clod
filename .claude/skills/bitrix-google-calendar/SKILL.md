# Задачи Битрикс24 → Google Календарь

Скрипт `scripts/sync.py` забирает задачи из Битрикс24 через входящий вебхук
и создаёт/обновляет события в Google Календаре. Напоминания (уведомления на
телефон и в браузер) присылает уже сам Google Календарь.

## Как задача превращается в событие

| В Битрикс24 | В Google Календаре |
|---|---|
| Крайний срок | Конец события (начало = срок − 30 мин) |
| Плановые даты начала/окончания (без срока) | Начало и конец события |
| Нет ни срока, ни плановых дат | Событие не создаётся |
| Название | `[Б24] Название` |
| Просрочена | `⚠️ [Б24] …`, красный цвет |
| Завершена / отклонена | `✅ [Б24] …`, серый цвет, без напоминаний (или удаляется при `COMPLETED_ACTION=delete`) |
| Описание, статус, ссылка на задачу | Описание события |

Напоминания по умолчанию — за 1 день и за 1 час (`REMINDER_MINUTES=1440,60`).
Дублей не бывает: id задачи хранится в скрытом свойстве события, при повторном
запуске событие обновляется, и только если в задаче что-то изменилось.

## Что делать

### 1. Проверить настройки

Нужны переменные окружения `BITRIX_WEBHOOK_URL`, `GOOGLE_CALENDAR_ID`,
`GOOGLE_SERVICE_ACCOUNT_JSON`. Если какой-то нет — проведи пользователя по
`references/setup.md` шаг за шагом (вебхук в Битриксе, сервисный аккаунт
Google, доступ к календарю). Никогда не записывай ключи и вебхук в файлы
репозитория и не выводи их целиком в чат.

### 2. Пробный запуск

```bash
pip install -r .claude/skills/bitrix-google-calendar/scripts/requirements.txt
python3 .claude/skills/bitrix-google-calendar/scripts/sync.py --dry-run
```

Покажи пользователю, какие события будут созданы/обновлены/удалены, и
спроси подтверждение перед настоящим запуском.

### 3. Синхронизация

```bash
python3 .claude/skills/bitrix-google-calendar/scripts/sync.py
```

В конце скрипт печатает итог: `created / updated / deleted / unchanged / skipped`.

### 4. Автоматический запуск

Чтобы уведомления приходили без участия человека, синхронизация должна
запускаться по расписанию. В репозитории есть готовый GitHub Actions
workflow `.github/workflows/bitrix-calendar-sync.yml` (каждые 15 минут).
Пользователю нужно добавить секреты в Settings → Secrets and variables →
Actions (см. `references/setup.md`, раздел «Автозапуск»). Альтернатива — cron
на своём сервере: `*/15 * * * * python3 /путь/sync.py`.

## Частые проблемы

- `Битрикс24 tasks.task.list: … insufficient_scope` — у вебхука нет права
  «Задачи (task)». Пересоздать вебхук с этим правом.
- `Google Calendar 404` — календарь не расшарен на e-mail сервисного аккаунта
  или неверный `GOOGLE_CALENDAR_ID`.
- `Google Calendar 403 … writer access` — календарь расшарен, но только на
  просмотр; нужно «Внесение изменений в мероприятия».
- Задачи не появляются — у задачи нет крайнего срока, либо она изменялась
  раньше, чем `LOOKBACK_DAYS` дней назад, либо `BITRIX_USER_ID` отсекает её.
- Удалённые в Битриксе задачи не удаляются из календаря автоматически
  (API их больше не возвращает) — такие события можно удалить вручную.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `BITRIX_WEBHOOK_URL` | — | Входящий вебхук, `https://портал.bitrix24.ru/rest/1/ключ/` |
| `GOOGLE_CALENDAR_ID` | — | Id календаря (почта или `…@group.calendar.google.com`) |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | — | JSON-ключ сервисного аккаунта (содержимое или путь к файлу) |
| `BITRIX_USER_ID` | все задачи вебхука | Только задачи, где этот пользователь участник |
| `REMINDER_MINUTES` | `1440,60` | Напоминания, минут до срока (до 5 штук) |
| `EVENT_DURATION_MINUTES` | `30` | Длина события, если есть только срок |
| `LOOKBACK_DAYS` | `90` | Брать задачи, изменённые за последние N дней |
| `COMPLETED_ACTION` | `mark` | `mark` — пометить ✅, `delete` — удалить событие |
| `TIMEZONE` | `Europe/Moscow` | Часовой пояс событий |
